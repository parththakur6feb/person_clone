# PersonaForge - Digital Persona Creator

PersonaForge is a web application that creates and manages digital personas from chat logs and message data. It analyzes conversational patterns, tone, and style to build faithful representations of people's communication habits.

## Features

### 🎭 Persona Management
- **Create Personas**: Add new personas by uploading chat data
- **Analyze Traits**: Automatically extract tone, common phrases, emoji usage, and interests
- **View Details**: Comprehensive persona profiles with extracted characteristics
- **Delete Personas**: Remove personas with confirmation prompts

### 💬 Interactive Chat
- **Role-Playing**: Chat with personas that respond in their unique style
- **Real-time Responses**: AI-generated responses based on persona traits
- **Chat History**: Maintain conversation context during sessions
- **Persona Selection**: Switch between different personas easily

### ⚙️ Customizable Settings
- **Safety Levels**: Adjust safety strictness (High/Medium/Low)
- **Faithfulness**: Control how closely responses match original style
- **Data Management**: Delete all data with confirmation

### 🔒 Privacy & Safety
- **Consent Verification**: Requires explicit consent before processing data
- **Data Deletion**: Complete data removal capabilities
- **Local Storage**: All data stored locally in browser
- **Safety Guardrails**: Built-in protections against harmful content

## Demo Personas

The application comes with two demo personas to showcase functionality:

1. **Alex** - A friendly, tech-savvy person who loves gaming and memes
2. **Sarah** - A professional, thoughtful person who enjoys reading and nature

## How to Use

### Adding a New Persona

1. Click "Add New Persona" button
2. Enter persona name and description
3. Paste chat logs or message data
4. Confirm you have explicit consent
5. Click "Create Persona"

### Chatting with Personas

1. Go to the "Chat" tab
2. Select a persona from the dropdown
3. Start typing messages
4. Receive responses in the persona's style

### Managing Settings

1. Go to the "Settings" tab
2. Adjust safety and faithfulness levels
3. Use "Delete All Data" to remove everything

## Technical Details

### Persona Analysis Engine

The system analyzes chat data to extract:

- **Tone**: Positive, negative, or neutral sentiment
- **Common Phrases**: Frequently used 2-word combinations
- **Emoji Usage**: Frequency and common emojis
- **Message Length**: Average character count per message
- **Interests**: Detected topics (technology, sports, music, etc.)
- **Humor Level**: Based on laughter indicators
- **Formality**: Formal, informal, or neutral communication style

### Response Generation

Personas respond based on their extracted traits:
- Tone influences response sentiment
- Formality affects language style
- Emoji usage determines emoji inclusion
- Message length guides response brevity
- Interests provide context for relevant topics

## Privacy & Ethics

- All data is stored locally in the browser

### Safety Measures
- Built-in guardrails against harmful content
- Configurable safety levels

## Browser Compatibility

- Modern browsers with JavaScript support
- Local storage required for data persistence
